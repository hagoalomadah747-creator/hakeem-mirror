# Hakeem — mirror

Mirror of [hakeemsim.com](https://hakeemsim.com) for networks that cannot reach the main site.

- **Download the Android app:** [Hakeem.apk (latest release)](https://github.com/hagoalomadah747-creator/hakeem-mirror/releases/latest/download/Hakeem.apk)
- Website mirror: https://hagoalomadah747-creator.github.io/hakeem-mirror/

Hakeem is an educational clinical case simulator for medical students and doctors. It is not a medical device and must not be used for decisions about real patients.
